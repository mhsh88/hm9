# Java servlet coursework

Maktab homework project exploring person CRUD operations with Java Servlets, Jackson, and MySQL.

## Layout

- `src/main/java/api/Person/`: person model and CRUD handlers.
- `src/main/java/api/dataBase/`: database access examples.
- `pom.xml`: Maven WAR configuration.

## Development

Import the Maven project into a Java IDE. Review database connection settings and prepare a local MySQL database before exercising persistence. Deploy the WAR to a container compatible with the project's `javax.servlet` dependencies.

This is historical coursework. The current JDK, database schema, and container setup have not been validated.
